# 4. «Стрик» (Streak / Combo System)

> ⏳ **Статус: Запланировано**

---

## Концепция

Серия правильных ответов подряд даёт нарастающий множитель очков. Ошибка сбрасывает стрик в ноль. Система пронизывает все режимы игры.

## Шкала множителей

| Стрик | Множитель | Название |
|-------|-----------|----------|
| 0–4   | ×1.0      | — |
| 5–9   | ×1.25     | Разогрев |
| 10–19 | ×1.5      | В ударе |
| 20–34 | ×2.0      | На волне |
| 35–49 | ×2.5      | Эксперт |
| 50+   | ×3.0      | Мегамозг |

## Формула

```
finalPoints = basePoints * streakMultiplier
```

Где `basePoints` — существующая формула `10 * 0.1^(time/limit)`, а `streakMultiplier` из таблицы выше.
