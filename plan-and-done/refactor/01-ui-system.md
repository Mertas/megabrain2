## 2. Целевая система

**2.1. Каркас страницы** (новое): `Page`-компонент-шаблон и его части:
- `PageHeader` — иконка (emoji), заголовок, подпись, слот `actions` (кнопки справа), опциональные «правила» (`items`).
  Заменяет и `Hero`, и ручные `<h1>`.
- `PageSection` (он же — бывший `ConfigCard`) — карточка с заголовком/подсказкой. Единый вид для всех страниц.
- `Toolbar` — строка поиска/фильтров/действий (для админки, людей, вопросов).
- `EmptyState` — единая заглушка «пусто» (иконка+текст+действие).
- `Loader` — единый индикатор загрузки (на базе `Spinner`).

**2.2. Токены стилей** (`styles/_variables.scss` + новый `_tokens.scss`):
- Цвета: bg, surface, border, text, muted, accent, primary, success, error + `--game-*` для режимов.
- Радиусы, тени, отступы (шаг 4px), размеры шрифтов, веса, z-index.
- Правило: **в модулях и TSX — только токены**, hex-литералы запрещены (кроме мест, где цвет данных — из API).

**2.3. Канон пропсов компонентов:**
- `Timer`: `value` (cs) + `total?` (cs) + `paused?`.
- `PowerupSelector`: `types`, `selected`, `onChange`, `max`, `showKeys`; алиасы удалить.
- `Hero` (→ `PageHeader`): `icon`, `title`, `description`, `rules?`, `actions?`.
- Кнопки: только `variant` (`primary|secondary|ghost|danger`) и `size` (`sm|md|lg`).

**2.4. Навигация и крошки — из одной карты маршрутов** (`lib/navItems.ts` → `lib/routes.ts`):
каждая запись: `key, path, label, icon, roles, breadcrumbs, title`. `Sidebar` фильтрует по ролям,
`PageWrap` берёт крошки/заголовок/активный пункт из карты (ручные массивы с страниц уходят).

**2.5. Группировка меню** (если выбрана): Игра · Выживание · Блиц-дуэль · PvP — группа «Игра»;
Рейтинги — «Соревнование»; Вопросы — «Контент»; Люди — «Сообщество»; Power-ups — «Магазин»; Админка.
