> ✅ **Статус: Реализовано** (2026-07-07)

## Аудит: что не так

Четыре страницы настройки игры выглядят как четыре разных продукта. Нет общего шаблона — каждый режим изобретает свой подход к заголовку, выбору тем, конфигурации и кнопкам.

### Несоответствия страниц настройки

| Элемент | Соло (NewGameForm) | Выживание (SurvivalSetup) | Блиц (Blitz) | PvP (PvP) |
|---------|-------------------|--------------------------|-------------|-----------|
| Hero-секция (иконка + описание) | ❌ Нет | ✅ Череп + текст | ⚠️ Есть описание, нет иконки | ❌ Нет |
| Выбор тем | `TopicList` | `TopicList` | `TopicList` | Плоские `Button`-ы |
| Заголовки секций | `<h2>` «Время», «Вопросы» | `<h2>` «Выберите темы» | `<h2>` «Темы», «Формат» | `<div>` без h2 |
| Конфигурация времени | Радио + Select (на вопрос / на игру) | ❌ Нет | Select (раунды + секунды) | Select (вопросы + секунды) |
| Правила / памятка | ❌ Нет | ✅ 5 строк с иконками | ❌ Нет | ❌ Нет |
| Рекорды | ❌ Нет | ✅ Счёт + стрик | ❌ Нет | ❌ Нет |

### Несоответствия игрового экрана (уже почти синхронизированы)

## План: что делаем

### Итерация 1: Единый hero-блок для всех страниц настройки

Каждая страница настройки должна начинаться одинаково:

```
┌─────────────────────────────────────────┐
│  [ИКОНКА]                               │
│  Заголовок режима                       │
│  Краткое описание (1-2 строки)          │
└─────────────────────────────────────────┘
```

Где сейчас нет — добавить:
- **Соло**: добавить hero с иконкой `§` и описанием «Классическая викторина. Выберите темы, настройте время и количество вопросов.»
- **PvP**: добавить hero с иконкой `⚔️` и описанием «Сразитесь с живым соперником. Одинаковые вопросы, одновременные ответы — побеждает самый эрудированный.»
- **Блиц**: добавить иконку `⚡` перед заголовком

#### Что создать

Новая молекула `Hero`:

```typescript
// molecules/Hero/Hero.tsx
interface HeroProps {
  icon: string
  title: string
  description: string
}
```

Заменить все 4 hero-секции на `<Hero icon="..." title="..." description="..." />`.

### Итерация 2: Заменить плоские кнопки тем в PvP на TopicList

PvP — единственный режим, где темы выбираются плоскими кнопками, а не компонентом `TopicList`. Визуально это сильно выбивается. Использовать `TopicList` с `mode="select"` как в остальных режимах.

**Изменения:**
- PvP.tsx: убрать `topicOptions` и `toggleTopic`, использовать `TopicList`
- Данные тем уже есть в `categories` из пропсов

### Итерация 3: Унифицировать секционные заголовки

Сейчас `<h2>` в секциях оформлены по-разному:
- Соло: `className={styles.sectionTitle}` (17px, default weight)
- Выживание / Блиц: `<Text as="h2" variant="muted" size="lg">`
- PvP: `<div>` с инлайн-стилем

Привести к `<Text as="h2" variant="muted" size="lg">` везде.

### Итерация 4: Унифицировать кнопки действий

| Режим | Сейчас | Станет |
|-------|--------|--------|
| Соло | `СТАРТ!` (lg) | `Начать игру` (lg) |
| Выживание | `НАЧАТЬ ВЫЖИВАНИЕ` (lg) | `Начать выживание` (lg) |
| Блиц | `ИСКАТЬ СОПЕРНИКА` (lg) | `Искать соперника` (lg) |
| PvP | `Искать соперника` (lg **fullWidth**) | `Искать соперника` (lg) |

Убрать `fullWidth` у PvP-кнопки (привести к общему стилю).

### Итерация 5: Унифицировать контейнеры

Все страницы настройки обернуть в `<div className={styles.wrap}>` с `max-width: 650px; margin: 0 auto; padding: 24px 0`.

Сейчас:
- Соло: без ограничения ширины
- Выживание: 700px
- Блиц: 650px  
- PvP: 650px

Привести к **650px** везде.

### Итерация 6: Результаты — единый шаблон

Унифицировать страницы результатов:

1. **Заголовок**: `<Text as="h1" variant="heading">` с текстом `«{Режим} завершён»` (вместо «Результаты игры», «Игра окончена», etc.)
2. **Мотивационная строка**: под заголовком, цвет зависит от результата
3. **Блок статистики**: 2×2 карточки в сетке (тотал / точность / время / очки)
4. **Детализация**: AnswerResultItem (соло) / раунды (блиц) / вопросы (PvP) / stats (выживание)
5. **Кнопки**: `<Flex gap={12} justify="center">` с единым отступом

### Итерация 7: Дополнительные мелочи

- В PvP и Blitz нет кнопки «Пропустить» вопроса — добавить
- В PvP и Blitz нет `GameQuitConfirm` — добавить
- Проверить, что PowerupBar выглядит одинаково во всех режимах
- Проверить отступы между секциями (margin-bottom)
